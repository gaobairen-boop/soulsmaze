# 魂之迷宮（SoulsMaze）原始碼備份

遊戲網址：https://gaobairen-boop.github.io/soulsmaze/

## 怎麼重建專案
1. 用 Unity Hub 建立新專案：Unity 6.6（6000.6.5f1）、範本選 **Universal 3D**
2. 把這個分支的 `Assets` 資料夾內容複製到新專案的 `Assets` 裡
3. 打開 SampleScene，按 ▶ 就能玩（迷宮、玩家、敵人都由程式自動產生）
4. 要更新網頁版：Unity Hub 加裝 Web Build Support → 上方選單「SoulsMaze → 打包網頁版 (WebGL)」
